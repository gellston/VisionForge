# VisionForge

VisionForge는 C++ 기반의 이미지 및 비전 기능을 위한 라이브러리입니다.
이미지 데이터를 다루는 기본 타입을 시작으로, 관련 클래스와 처리 함수를 점진적으로 추가합니다.

이 문서는 프로젝트 전체의 공통 규칙과 현재 제공하는 기능을 설명합니다.
새로운 기능이 추가되면 아래 기능 목록과 사용 예제를 함께 업데이트합니다.

## 기본 환경

- C++17 이상
- 공개 네임스페이스: `visionforge::v1`
- 현재 구현은 C++ 표준 라이브러리만 사용합니다.

## 설계 및 명명 규칙

- 클래스, 함수, 타입 별칭은 소문자 `snake_case`로 작성합니다.
- 공개 클래스와 자유 함수는 `visionforge::v1`에 배치합니다.
- 내부 상태를 갖는 클래스는 PImpl을 활용해 구현과 멤버 변수를 공개 헤더에서 숨깁니다.
- PImpl의 소멸자와 필요한 특수 멤버 함수는 구현 타입이 정의된 `.cpp` 파일에서 정의합니다.
- 자원은 RAII로 관리하고, 복사·이동 시 소유권과 데이터 공유 여부를 명확히 정합니다.
- 공개 스마트 포인터 타입은 `shared_image`, `shared_const_image`, `unique_image`처럼 소유 방식과 대상 타입을 드러냅니다. 새 클래스에도 같은 형식을 적용하며, `ptr`처럼 대상이 드러나지 않는 별칭은 사용하지 않습니다.
- 클래스의 상태나 수명과 관계없는 처리는 자유 함수로 추가할 수 있습니다. 관련 기능을 모두 `image`의 멤버 함수에 넣을 필요는 없습니다.
- 공개 API에는 입력 조건, 반환값, 단위, 데이터 배치, 예외, 포인터 유효 기간을 문서화합니다.

## 현재 제공하는 기능

| 구성 요소   | 역할                       | 공개 헤더                    |
| ------- | ------------------------ | ------------------------ |
| `image` | 이미지 버퍼 소유 및 크기·채널·메모리 접근 | [`image.hpp`](image.hpp) |

### image

`image`는 채널당 1바이트인 이미지 버퍼를 소유합니다.
각 픽셀의 채널을 연속으로 배치하며, 행 사이에 추가 패딩은 없습니다.
RGB 또는 BGR 같은 채널의 의미는 지정하지 않습니다.

| API | 설명 |
| --- | --- |
| `image()` | 빈 이미지 생성 |
| `image(width, height, channel)` | 지정한 크기의 버퍼를 생성하고 모든 바이트를 0으로 초기화 |
| `width()` | 가로 픽셀 수 |
| `height()` | 세로 픽셀 수 |
| `channel()` | 픽셀당 채널 수 |
| `stride()` | 한 행의 바이트 수. 현재는 `width() * channel()` |
| `data()` | 쓰기 가능한 버퍼 시작 주소 |
| `data() const` | 읽기 전용 버퍼 시작 주소 |

크기 지정 생성자의 모든 인자는 0보다 커야 합니다.
0이 전달되면 `std::invalid_argument`, 크기 곱셈이 `std::size_t` 범위를 넘으면 `std::length_error`가 발생합니다.
버퍼가 컨테이너의 최대 크기를 초과하거나 메모리가 부족하면 표준 컨테이너의 할당 관련 예외가 발생할 수 있습니다.

복사 생성과 복사 대입은 픽셀 버퍼를 독립적으로 복사합니다.
이동은 버퍼의 소유권을 전달하며, 이동된 원본은 빈 이미지가 됩니다.
빈 이미지는 크기·채널·stride가 모두 0이고 `data()`는 `nullptr`입니다.

`data()`가 반환한 메모리는 이미지가 소유하므로 호출자가 해제하면 안 됩니다.
이미지가 파괴되거나 대입으로 기존 버퍼가 교체되면 해당 버퍼의 포인터는 무효가 됩니다.
이동 시 기존 버퍼의 수명은 이동 대상 이미지가 관리합니다.

#### 스마트 포인터 타입

| 타입 | 정의 | 용도 |
| --- | --- | --- |
| `image::shared_image` | `std::shared_ptr<image>` | 수정 가능한 이미지의 공동 소유 |
| `image::shared_const_image` | `std::shared_ptr<const image>` | 읽기 전용 접근을 통한 공동 소유 |
| `image::unique_image` | `std::unique_ptr<image>` | 이미지의 단독 소유 |

`shared_const_image`는 해당 포인터를 통한 수정을 제한합니다.
같은 객체를 참조하는 `shared_image`가 있다면 그 포인터를 통해 내용이 변경될 수 있습니다.

## 사용 예제

```cpp
#include "image.hpp"

#include <memory>

int main()
{
    visionforge::v1::image::shared_image shared =
        std::make_shared<visionforge::v1::image>(640, 480, 3);

    visionforge::v1::image::shared_const_image readonly = shared;

    visionforge::v1::image::unique_image unique =
        std::make_unique<visionforge::v1::image>(640, 480, 1);

    // (x = 10, y = 20) 픽셀의 첫 번째 채널에 접근합니다.
    shared->data()[20 * shared->stride() + 10 * shared->channel()] = 255;

    // image 객체 자체를 복사하면 별도의 픽셀 버퍼가 생성됩니다.
    visionforge::v1::image copied = *readonly;
    copied.data()[0] = 128;

    unique->data()[0] = 64;
}
```

현재 별도의 빌드 설정은 제공하지 않습니다.
사용하는 프로젝트에서 C++17 이상을 활성화하고, 헤더 검색 경로에 이 저장소를 추가한 뒤 `image.cpp`를 소스 목록에 포함합니다.

## 기능 확장 시 작성 기준

새로운 클래스나 함수를 추가할 때는 다음 내용을 함께 정리합니다.

1. 기능 목록에 이름, 역할, 공개 헤더를 추가합니다.
2. 클래스 또는 함수의 최소 사용 예제를 작성합니다.
3. 입력 범위와 오류 처리 방식을 명시합니다.
4. 이미지를 받거나 반환한다면 지원하는 채널 수, 데이터 형식, 원본 수정 여부, 결과 버퍼의 소유권을 설명합니다.
5. 변경 범위에 맞춰 정상 동작과 경계 조건을 검증합니다. 소유권을 다루는 기능은 복사·이동·객체 수명도 확인합니다.

이미지 입출력, 변환, 필터, 추가 데이터 타입 등은 향후 확장 가능한 영역입니다.
현재 제공되는 API는 위 기능 목록에 기재된 항목을 기준으로 합니다.
